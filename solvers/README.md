# Modular Solvers

Experimental ARC-AGI solvers, each exploring a different theoretical approach.

| Solver | Approach | Description |
|--------|----------|-------------|
| `curiosity_solver/` | Curiosity-driven active inference | Bayesian belief updating with curiosity signals and hierarchical reasoning |
| `graph_pendulum/` | Dynamical systems | Stability-aware graph-based reasoning with pendulum dynamics |
| `generative_solver/` | Generative task discovery | Typed rule grammar with program synthesis and active inference |

See the [unified solver](../unified_solver/) for an integrated approach that combines ideas from all three.
